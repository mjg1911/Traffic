# Blank Map Creation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a top-right action that creates a blank map while preserving the existing starter-city action.

**Architecture:** Add the new action to the existing header buttons and reuse the replacement dialog with mode-specific text and return values. Parameterize the current restart flow so the blank path resets shared city state and camera but skips starter roads, zones, and population.

**Tech Stack:** HTML, CSS existing button styles, browser JavaScript.

## Global Constraints

- A blank map keeps the river and landscape while clearing roads, zones, buildings, and traffic.
- The existing left-panel **New city** action still creates the prebuilt starter city.
- No save format changes are needed.
- Do not add or run automated tests for this change.

### Task 1: Add the blank-map action and reset mode

**Files:**
- Modify: `index.html`
- Modify: `game.js`

**Interfaces:**
- `restart(blankMap = false)` keeps its current behavior for callers without an argument and skips starter generation when `blankMap` is true.
- `openNewDialog(blankMap)` presents the correct confirmation wording and records the action as either `new` or `blank`.

- [x] **Step 1: Add the header button and dialog copy targets.** Insert this button before Save city in `.city-actions`:

```html
<button id="btn-new-map" title="Create a blank map">New map</button>
```

Give the dialog title and description the IDs `new-title` and `new-description`. Keep the cancel value as `cancel` and the confirmation button ID as `new-confirm`.

- [x] **Step 2: Make the restart path conditional.** Change the restart signature and replace its unconditional scene generation with:

```js
  CITY.init();
  if (blankMap) CITY.reattachDirty = false;
  else {
    initScene();
    populateStarter();
  }
```

- [x] **Step 3: Bind both actions to the shared dialog.** Add `openNewDialog(blankMap)` near the UI bindings. Set title, description, confirmation text, and confirmation value from `blankMap`; set `dialog.returnValue = 'cancel'` before `showModal()`. Bind `btn-restart` with `openNewDialog(false)` and `btn-new-map` with `openNewDialog(true)`. In the dialog close handler, call `restart()` for `new` and `restart(true)` for `blank`.

- [x] **Step 4: Update the game script cache version.** Increment `game.js?v=13` in `index.html` to `game.js?v=14`.

- [x] **Step 5: Review and run non-test checks.** Inspect only the feature diff. Run `node --check game.js` and `git diff --check`; do not run automated tests.
